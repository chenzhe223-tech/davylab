# WorkBuddy 执行手册：DAVYLAB 公众号稿件仅存草稿

## 目标
将 GitHub 已确认稿件录入微信公众号后台、保存草稿并通过手机预览检查。自动化止于验收通过的草稿，不自动公开发布。

## 1. 读取稿件
读取：
- `wechat-ops/drafts/2026-10-20-ai-can-generate-not-equal-usable/article.md`
- `publish.json`
- `review.md`
- `sources.md`
- `ASSET_MANIFEST.md`

标题必须与 `publish.json` 的 title 完全一致。发现 review 阻断项、必需素材缺失或信息不一致时先停止并汇报。

## 2. 封面检查
- 头条封面 1800×766、约 2.35:1、JPG/PNG、≤2MB。
- 如新编辑器要求 1:1 分享卡，再准备独立方图；禁止拉伸横图。
- 设计克制高级，颜色不宜过多；保留有意义的发光路径设计。
- 封面标题使用文章正式标题逐字核对。
- 不使用模型生成的二维码，不把虚构 UI 作为真实产品证据。

## 3. 清洁重录正文
1. 打开后台并确认账号为 DAVYLAB。未登录或要求验证码时交给用户本人处理。
2. 若当前草稿已含旧排版，先备份可恢复内容，再清空正文后重录，不在旧版后追加。
3. 标题只放标题字段；封面只放封面字段。
4. 正文不要放重复主标题图、品牌开场 banner、旧版海报或封面。正文首屏必须从引导语/第一段文字开始。
5. 使用简单、稳定的格式：正文 15–16 px、行距约 1.75–1.9；小标题 20–21 px、深色高对比；图注 12–13 px。避免整页背景图和低对比颜色。
6. 正文配图必须从实际素材上传至公众号编辑器，不能依赖本地路径或未验证链接；保持比例，不拉伸。

## 4. 保存与验收
保存草稿后返回列表确认，再重新打开。
手机预览逐项检查：
- [ ] 文章主标题与用户指定的标题一致。
- [ ] 封面没有明显裁切，比例正常，文字可读。
- [ ] 正文首屏无旧 banner、无重复标题图。
- [ ] 标题字段、封面字段、正文互相独立。
- [ ] 正文字体、行距、颜色对比适合手机阅读。
- [ ] 正文图片顺序、清晰度、比例正确。
- [ ] 正文开头、中段、结尾均完整，无缺图或断段。
任一项失败即不得标记 preview-passed。修复并重新预览。

## 5. 安全边界
- 不点击发表、群发、发布、立即发布、定时发布。
- 不修改菜单/账号设置/自动回复。
- 不绕过登录、验证码或安全控制，不保存 Cookie、密码或令牌。
- 将每项标为“已验证 / 未验证 / 失败”，不要把尝试描述为成功。
- 结尾明确：正式发布未执行，等待作者本人审核后手动发布。
