# DAVYLAB 公众号工作流验收清单

## 1. GitHub 稿件交接
- [ ] 存在 article.md、publish.json、review.md、sources.md。
- [ ] 标题、摘要、正文非空。
- [ ] publish.json 状态为 ready-for-workbuddy。
- [ ] 来源链接可访问；无法核实的事实已标注。
- [ ] 不含密码、Cookie、验证码、令牌或其他秘密。

## 2. WorkBuddy 浏览器操作
- [ ] 使用用户本人已登录的公众号后台。
- [ ] 账号名称确认是 DAVYLAB。
- [ ] 标题、摘要、正文、封面与 GitHub 稿件一致。
- [ ] 后台明确提示保存成功，或草稿列表可见。
- [ ] 重新打开草稿后，正文与封面仍存在。
- [ ] 未点击发表、群发、发布或定时发布。

## 3. 人工审核
- [ ] 手机预览检查段落、图片、封面与可读性。
- [ ] 事实、数据、引用、链接及版权检查完成。
- [ ] 标题和摘要符合文章内容。
- [ ] 用户本人决定是否正式发布。

只有完成第 1、2 部分，才能标记 `draft-saved-in-wechat`。任何关键步骤未完成时，记录为待处理；不能把「已尝试」描述成「已成功」。
