# DAVYLAB 首次公众号发布复盘：踩坑与后续强制规则

复盘依据：作者提供的微信临时预览截图、封面需求与本轮实际制作过程。下文区分截图中可以确认的问题与需要预防的潜在原因，不把推测当作已证实事实。

## 一、已经暴露的问题

### 1. 标题多次偏离文章正式标题
封面曾使用“从小白到能用，我的 AI 产品开发之路”等替代文案，和作者最终指定标题不一致。后续应把一个唯一正式标题写入元数据，封面设计、公众号标题字段、预览核对都引用同一标题，禁止设计环节自行改写。

**唯一正式标题：** 我用 AI 做了几个应用后，才发现：能生成，不等于能用

### 2. 封面过于复杂，视觉层级不够克制
多色渐变、多个应用卡片、复杂背景和大量小字同时争抢注意力。生成式图像也可能出现错误文字、伪造 UI 或不准确的 Logo。

后续规则：
- 主色控制为深海军蓝/蓝灰，辅以少量品牌蓝紫或暖金；不要彩虹渐变和过多高饱和色。
- 保留对文章有意义的视觉记忆点，例如原图的发光路径与里程碑节点，但减少装饰卡片和微小文案。
- 真实产品截图优先；生成式图像只负责氛围与构图。品牌字样、中文标题、Logo 如有条件应后期准确排版并人工校对。
- 任何封面必须用实际文件检查尺寸、比例、格式、文件大小和标题是否准确，不能只凭生成描述宣称合规。

### 3. 封面规格需要一次说清楚
用户提供的公众号要求为：
- 头条封面：1800×766 px，约 2.35:1，JPG/PNG，文件 ≤ 2 MB。
- 新编辑器如果要求 1:1 分享卡，需单独制作 1:1 图片；不能把横版封面拉伸成方形。
- 上传后还需检查编辑器裁切方式与实际预览。

### 4. 封面与正文内容混在一起
微信预览截图里，正文开头出现了旧版 DAVYLAB 品牌开场图，内容为“把想法，做成能用的工具”，其后又出现一张重复文章主标题的大图。这使正文在读者真正看到内容之前就被大型图片占据。

后续规则：
- 文章标题只填写在公众号标题字段。
- 封面只放封面字段，不能再塞入正文。
- 正文不得重复插入品牌开场 banner、旧封面、标题海报或重复一级标题图片。
- 每次重做排版前先备份，再清空旧正文后重录，不在旧版内容后面追加。

### 5. 可能把网页预览样式直接带入公众号编辑器
完整 HTML 视觉预览是用来检查设计的，不等于把整个网页（含品牌头图、整页背景、标题卡片与本地图片路径）整体粘贴进公众号。若复制方式不当，可能造成版式失控或图片丢失。

后续规则：
- 公众号正文只使用正文专用 HTML/格式化内容；不将网站完整页面当作文章内容。
- 图片必须在公众号编辑器中实际上传，不能依赖本地 file:/// 路径。
- 封面图与正文配图分开管理，每张图在正文中的位置有明确说明。

### 6. 缺少发布前手机端验收门槛
后台保存成功并不等于手机端排版通过。临时预览链接可能过期，所以应从公众号后台重新生成预览，检查实际草稿，而不是沿用旧预览链接。

后续规则：必须逐项检查首屏、标题、正文段落、图片比例与顺序、文字对比、文章结尾。任何一项失败都要修复后重验。

### 7. 设计/方案被误当作完成结果的风险
产品图、架构图、同步、安全、加密等内容可能只反映某个界面或设计意图，并不自动证明功能已在生产环境验证。

后续规则：
- 明确标记方案、开发中、已实现、已实测四种状态。
- 不用概念图证明生产安全能力。
- 不声称未实际验证的保存、同步、封面尺寸、草稿或发布结果已经成功。

## 二、每次发布前的强制验收清单

### A. 内容
- [ ] 标题严格匹配唯一元数据，不在封面或正文擅自改写。
- [ ] 文章事实、产品状态、个人经历和用户反馈经作者核对。
- [ ] 正文无重复标题图、旧品牌 banner、重复封面。
- [ ] 正文开篇直接进入故事/引导语，不先放满屏大图。

### B. 封面与图片
- [ ] 头条封面实际尺寸为 1800×766，JPG/PNG，≤2 MB。
- [ ] 若后台要求 1:1 分享卡，另有独立方图。
- [ ] 主标题逐字核对，无错别字、遗漏、错误标点。
- [ ] 视觉颜色克制，主视觉明确，有呼吸空间。
- [ ] 优先真实产品截图；图像模型生成的文字、Logo 与 UI 已审查。
- [ ] 所有正文图片均上传至公众号编辑器，实际加载正常，无变形、模糊或空白。
- [ ] 不使用 AI 生成二维码；只用作者提供并验证过的真实二维码。

### C. 移动端预览
- [ ] 正文首屏直接显示引导语/正文内容。
- [ ] 标题不重复出现为一张大图。
- [ ] 正文建议 15–16 px，行距约 1.75–1.9；小标题 20–21 px；图注 12–13 px。
- [ ] 文字与背景对比清晰，避免整页背景色块和过浅文字。
- [ ] 检查文章开头、中段、结尾；图片与图注顺序正确。
- [ ] 从公众号后台重新生成预览；旧的临时链接不作为最终验收凭据。

### D. 草稿保存与发布
- [ ] 保存后回到草稿列表确认文章存在。
- [ ] 重新打开草稿核对标题、封面、正文与图片。
- [ ] 报告中区分“素材已准备”“草稿已保存”“手机预览通过”“正式发布”。
- [ ] 自动化只到草稿和预览验收；正式发表/群发由作者本人确认并手动操作。
