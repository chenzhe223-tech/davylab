# DAVYLAB 日常选题触发卡

在 ChatGPT 中，只需直接发送类似下面的一句话即可启动内容准备：

> 公众号选题：我今天在 Dashboard Studio 中解决了 AI 生成看板布局不稳定的问题。请按 DAVYLAB 标准准备文章，先核实我提供的信息，再生成 GitHub 稿件包；完成后等待我确认是否交给 WorkBuddy 保存草稿。

也可以使用：
- `公众号选题：今天我发现的一个 AI 工具`
- `公众号选题：一个产品从想法到上线的真实过程`
- `公众号选题：普通人如何用 AI 把一个念头做成工具`

## 每次触发的流程
1. 识别选题和目标读者。
2. 需要时向用户询问缺失的关键事实。
3. 生成标题备选、摘要、正文和来源。
4. 生成 review 检查清单。
5. 将稿件文件提交到 DAVYLAB GitHub 仓库的独立目录。
6. 等用户确认稿件可以交接。
7. WorkBuddy 按执行手册在公众号后台保存草稿。
8. 用户本人最终审核并手动发布。

## 默认不自动做的事
- 不自动选择未经用户确认的敏感或争议性选题。
- 不凭空生成真实二维码或声称链接已经验证。
- 不自动进入公众号后台。
- 不自动发布、群发或定时发布。
