# DAVYLAB 日常选题触发卡

在 ChatGPT 中发送：

> 公众号选题：今天我发现/完成了什么；形式：文章 / 贴图 / 视频 / 播客

示例：
- 公众号选题：今天我修复了 Dashboard Studio 的布局问题；形式：文章。
- 公众号选题：用 5 张图讲清楚普通人如何用 AI 做一个小工具；形式：贴图。
- 公众号选题：演示从需求到可运行页面的过程；形式：视频。
- 公众号选题：聊聊普通人开始做 AI 产品时最容易遇到的问题；形式：播客。

若没有指定形式，ChatGPT 先推荐一种并等待确认，不要默认创建四种内容包。

## 流程
1. 识别读者、价值、栏目、行动目标和内容形式。
2. 对无法安全推断的关键事实提出必要问题。
3. 准备正文/脚本、标题/简介、素材清单、来源和授权记录。
4. 创建独立内容包并运行校验。
5. 用户确认且没有阻断项后，才允许交给 WorkBuddy。
6. WorkBuddy 核对 DAVYLAB 账号，进入匹配的后台入口并保存草稿。
7. 用户本人检查手机端预览、事实、版权及媒体播放后，手动决定是否发布。

## 不自动做的事
- 不自动进入公众号后台；不绕过登录验证。
- 不编造二维码、引用、数据或媒体资产。
- 不使用未经授权素材。
- 不因入口不可用而擅自改成另一种形式。
- 不自动发布、群发或定时发布。
