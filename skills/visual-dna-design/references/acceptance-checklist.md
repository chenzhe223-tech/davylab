# Visual DNA 实施验收清单

## 代码与范围

- [ ] 已确认应用框架、入口、路由、主题机制、公共组件和当前测试。
- [ ] 已识别本次允许修改的页面和禁止修改的冻结页面。
- [ ] 未删除原有功能、业务数据、API、状态或多端预览。
- [ ] 新增 CSS / JS 使用命名空间或作用域，不污染其他页面。
- [ ] 未用假数据、虚构运行状态或占位结果冒充真实功能。

## 视觉身份

- [ ] 风格由业务场景决定，不是套统一的深色侧栏 + 四张 KPI 卡。
- [ ] 有清晰的标题、正文、辅助说明、关键动作与状态层级。
- [ ] 主题不只修改背景，还作用于导航、卡片、按钮、输入框、图表、状态和焦点环。
- [ ] 关键颜色有对比度检查；状态不只靠颜色区分。
- [ ] 圆角、间距、边框和阴影有 Token，层级一致。

## 内容区域与布局

- [ ] 工作台主内容宽度至少为导航扣除后可用主区域的 90%。
- [ ] 没有遗留固定 max-width 导致的宽屏大空白。
- [ ] 页面横向留白随视口响应；不让文字贴边。
- [ ] 六种布局实际改变模块关系，而不是换皮。
- [ ] 同一网格行卡片自然等高，顶部与底部对齐。
- [ ] 没有使用无条件 height:100% 强制拉伸。
- [ ] 空状态可以伸展；真实数据、日志、图表和表格不会被裁切。
- [ ] 没有横向溢出、内容覆盖导航、工具栏挤压或下拉菜单出界。

## 导航与交互

- [ ] 顶部、左侧、右侧、底部、悬浮、隐藏模式都能工作。
- [ ] 隐藏模式保留可见的唤出入口；不依赖 hover。
- [ ] 收起/展开保留图标入口和可访问名称。
- [ ] 键盘可访问，Esc 关闭隐藏菜单，focus-visible 清晰。
- [ ] 手机导航不会与底部安全区域或主要按钮重叠。

## 主题、字体和存储

- [ ] 主题、颜色、布局、导航和字体可以分别设置并持久化。
- [ ] 恢复某项设置只重置该项，不清空其他设置。
- [ ] 浏览器存储失败、JSON 损坏或私密模式不会导致页面崩溃。
- [ ] 字体选择实际作用于文本并有实时预览。
- [ ] Arial / Times New Roman 仅作系统回退，不打包其字体文件。
- [ ] 所有自托管字体的 @font-face 使用 font-display: swap。
- [ ] 中文字体构建覆盖常见 UI 字符、标点、数字和动态文案。
- [ ] 字体的具体许可证覆盖网站嵌入、自托管、转换与子集化场景；不确定的资源不自动打包。
- [ ] 字体文件、许可证、请求状态和关键字形均已验证，没有把回退误报为成功。

## 响应式与质量门禁

- [ ] 目标桌面尺寸实际测量内容宽度比率。
- [ ] 至少检查 1440px/1366px 桌面、约 900–1100px 平板和约 390–430px 手机。
- [ ] 检查默认主题和自定义主题。
- [ ] 检查六种布局中的关键视口。
- [ ] 检查默认导航、左右导航、底部导航和隐藏/悬浮导航。
- [ ] 跑已有语法、单元、集成、API 契约和回归测试。
- [ ] 对齐测试通过真实浏览器测量（同一行卡片顶部/底部差值 0px 为理想值）。
- [ ] 发布后实际打开正式地址并核对部署版本，未验证不声称上线。
